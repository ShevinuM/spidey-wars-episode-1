# Spidey Wars — Episode 1

A Phaser 4 + Vite + TypeScript browser game.

## Commands

- `pnpm install` — install dependencies
- `pnpm dev` — run the dev server
- `pnpm build` — production build to `dist/`
- `pnpm build:test` — instrumented build to `dist-test/`
- `pnpm preview` — preview a production build
- `pnpm typecheck` — `tsc --noEmit`
- `pnpm lint` — oxlint
- `pnpm architecture` — dependency-cruiser boundary checks
- `pnpm format` — check formatting with Prettier
- `pnpm format:write` — apply Prettier formatting
- `pnpm duplication` — jscpd duplicate-code check
- `pnpm knip` — unused files/exports/dependencies check
- `pnpm check` — runs typecheck, lint, architecture, format, duplication, and knip
